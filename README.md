# Terminal-Tracker-For-Job-Applications-

A basic Python tracker for Job applications that can do the following: 

- Record each application.
- Automatically timestamp it.
- See applications today.
- See applications this week.
- Track progress toward 50/week ( You can adjust your goal).
- See how many applications remain.
- Keep a history of previous weeks.
- Optionally record company, job title, and status.
